# Save this ChatGPT conversation to Actario

This ChatGPT connection can read sessions already saved in Actario, but it
cannot capture or upload the conversation currently happening here. Do not
claim that the conversation was saved, and do not use another tool to imitate
a capture.

When the user asks to save this conversation, say plainly that saving a
current ChatGPT conversation is not available through this connection. The
local Actario plugin on a computer can capture conversations from supported
local clients. Offer to prepare a short summary for the user to copy if that
would help, and make clear that a summary is not an Actario capture.

Never create a share link to imply that this current conversation was saved.
